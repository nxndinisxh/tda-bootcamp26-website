# TDA Bootcamp '26 Portal 🧪⚡

The official portal for **The Data Alchemists (TDA) Bootcamp '26**, providing track progress tracking, resources, and leaderboards for bootcamp participants.

---

## ⚙️ Quick Start

### 1. Installation
Install dependencies in the root directory:
```bash
npm install
```

### 2. Development
Run the local backend and frontend development servers concurrently:
```bash
npm run dev
```

### 3. Production Build
Compile the client application for production serving:
```bash
npm run build
```
